# Productized Service Framework (MVP)

**Phase:** 2 (Productized Service)
**Status:** Active Execution Playbook
*(Note: Replaces the traditional SaaS MVP Framework for this phase)*

---

## 1. Purpose
In Phase 2, you are not building a software MVP. You are building a **Service MVP**. 
The goal is to test if the market will pay a fixed price for a standardized service outcome before you spend weeks building complex delivery systems or hiring contractors.

## 2. Anatomy of a Productized Service
A successful productized service has three elements:
1. **Target:** A specific, niche audience (e.g., AI SaaS founders).
2. **Outcome:** A guaranteed, specific result (e.g., A converting landing page design).
3. **Constraint:** A specific parameter (e.g., Delivered in exactly 7 days).

## 3. How to Launch Your First Service MVP

### Step 1: Identify the "Cash Cow" Service
Look at your Phase 1 freelance work. What did clients request the most? What are you fastest at delivering?
- *Example:* Connecting OpenAI APIs to React front-ends.

### Step 2: Package It
Create a strict boundary around what is included and what is not.
- **Included:** 1 React Component, 1 API integration, Basic Error Handling.
- **Excluded:** Backend database architecture, custom complex UI animations.

### Step 3: The Landing Page MVP
Do not build complex client portals or automated billing systems yet.
Build a simple Carrd, Webflow, or Next.js landing page with:
1. The clear Value Proposition.
2. The pricing tiers.
3. A "Book a Call" button (Calendly) or a direct Stripe Checkout link.

### Step 4: Fulfillment System MVP
For your first 3 clients, use manual "duct-tape" systems:
- A shared Notion page for the client portal.
- A Trello board for task management.
- Email for updates.

## 4. Iteration and Scaling
Once you have sold the package 3 times, you have validated the Service MVP.
*Then* you can invest time in:
- Building an automated Typeform onboarding flow.
- Setting up a custom client portal.
- Creating strict delivery SOPs so you can hire a Phase 3 junior developer to execute the work.
