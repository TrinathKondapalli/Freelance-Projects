# Performance Review Framework

**Version:** 1.0 **Status:** Founding Performance Excellence Operating
System **Parent Documents:** Company Handbook.md, Hiring Principles.md,
Onboarding Framework.md

------------------------------------------------------------------------

# Purpose

Define how employee performance is measured, coached, developed,
recognized, and continuously improved.

Performance reviews exist to help people grow while achieving meaningful
business outcomes.

------------------------------------------------------------------------

# Performance Philosophy

Measure outcomes, not activity.

Support continuous improvement through coaching, feedback,
accountability, and learning.

------------------------------------------------------------------------

# Guiding Principles

-   Customer impact first
-   Fair and transparent evaluation
-   Continuous feedback
-   Evidence-based assessments
-   Growth mindset
-   Ownership and accountability

------------------------------------------------------------------------

# Performance Framework

Evaluate every team member across:

-   Business Results
-   Quality of Work
-   Customer Impact
-   Collaboration
-   Ownership
-   Communication
-   Learning & Growth
-   Innovation

------------------------------------------------------------------------

# Goal Setting

Each review cycle begins with:

-   Objectives
-   Key Results (OKRs)
-   Role KPIs
-   Development Goals
-   Learning Plan

Goals must be measurable and aligned with company strategy.

------------------------------------------------------------------------

# Review Cycle

Weekly: - One-on-one check-in

Monthly: - Progress review

Quarterly: - Formal performance review

Annually: - Career and compensation review

------------------------------------------------------------------------

# Feedback Model

Feedback should be:

-   Timely
-   Specific
-   Evidence-based
-   Respectful
-   Actionable

Balance strengths with opportunities for improvement.

------------------------------------------------------------------------

# Performance Inputs

Use multiple sources:

-   Self-assessment
-   Manager review
-   Peer feedback
-   Customer feedback (where applicable)
-   KPI results
-   Project outcomes

------------------------------------------------------------------------

# Career Development

Every review should include:

-   Career aspirations
-   Skill gaps
-   Training recommendations
-   Stretch assignments
-   Promotion readiness

------------------------------------------------------------------------

# Recognition

Recognize:

-   Outstanding customer impact
-   Innovation
-   Team collaboration
-   Leadership
-   Continuous improvement

Celebrate behaviors that reflect company values.

------------------------------------------------------------------------

# Performance Improvement Plan (PIP)

When needed define:

-   Performance gaps
-   Expected outcomes
-   Support provided
-   Timeline
-   Review milestones

The objective is improvement, not punishment.

------------------------------------------------------------------------

# Success Metrics

Track:

-   Goal achievement
-   Employee engagement
-   Retention
-   Promotion rate
-   Learning completion
-   High performer retention
-   Manager effectiveness

------------------------------------------------------------------------

# Review Checklist

☐ Goals reviewed

☐ KPIs evaluated

☐ Feedback documented

☐ Development plan created

☐ Recognition provided

☐ Next objectives agreed

------------------------------------------------------------------------

# Common Mistakes

-   Focusing only on weaknesses
-   Surprising employees during reviews
-   Ignoring continuous feedback
-   Measuring effort instead of outcomes
-   Unclear expectations

------------------------------------------------------------------------

# Final Principle

Performance reviews should inspire better performance.

The best review process develops exceptional people while strengthening
the company and delivering greater value to customers.
